# NIDDEAW CUP — สเปกทัวร์นาเมนต์ของก๊วน

สเปกนี้ยังเป็นร่าง หัวข้อ "ยังต้องตัดสินใจ" ท้ายไฟล์คือเรื่องที่ยังไม่ได้ตกลง

ต้นแบบคืองาน DAISY GUMMY (14 พ.ย. 2569, T.Thailand Arena บางใหญ่) ที่จัดด้วย Google Sheets
ระบบแข่ง (แบ่งกลุ่ม 4 ทีม → น็อคเอาท์แยกสายบน/สายล่าง) ยกมาจากงานนั้น
ส่วนที่เขาทำด้วยมือ (ประเมินมือจากคลิป, ออกตาราง, จัดสนาม, คิดอันดับ, ชิปค่าลูก)
แอปเราทำให้เองจาก ELO, LINE และเครดิตที่มีอยู่แล้ว

## 1. มือ

| มือ | ระดับ ELO | ช่วงคะแนน |
|---|---|---|
| Milk–Beer | Milk, Beer | ต่ำกว่า 1100 |
| Highball | Highball | 1100–1299 |
| Wine | Wine | 1300–1499 |
| Soju ขึ้นไป | Soju, Whisky, Vodka, Absinthe | 1500 ขึ้นไป |

ช่วงคะแนนตรงกับ `_TIER_THRESHOLDS` ใน `backend/app/services/elo_service.py`
แอดมินแก้ชื่อมือและช่วงคะแนนได้ทีละงาน ค่าด้านบนเป็นค่าเริ่มต้น

- **มือของคู่ = มือของคนที่เก่งกว่า** เช่น Beer + Wine ต้องลงมือ Wine
- **ลงมือสูงกว่าได้ ลงมือต่ำกว่าไม่ได้** คู่ Milk + Beer จะไปลงมือ Highball ก็ได้
- **ขึ้นมือได้ ไม่ลงมือ** ระบบเช็คมือตอนสมัคร แล้วเช็คอีกครั้งตอนปิดรับสมัคร
  ถ้า ELO ขึ้นจนเกินช่วง ทีมจะถูกเลื่อนขึ้นมือ และแอดมินเห็นแจ้งเตือน
  ถ้า ELO ตกลงช่วงนั้น ทีมยังอยู่มือเดิม กันการตั้งใจแพ้เพื่อไปลงมือต่ำ
- หลังปิดรับสมัคร ระบบเก็บ ELO ของแต่ละคนไว้ (snapshot) ใช้จัดกลุ่มและแสดงผล ELO จริงขยับได้ตามปกติ

## 2. สมัครลงแข่ง (เฟส 1)

เปิดรับเฉพาะสมาชิกก๊วนที่ผูก LINE แล้ว คนนอกก๊วนต้องสมัครสมาชิกก่อน (มีปุ่มพาไปหน้าสมัครสมาชิกเดิม)

### 2.1 หน้าเว็บ `/tournament` (สาธารณะ ไม่ต้องล็อกอิน)

ใช้แทนหน้า Coming Soon เดิม แสดง:

- ชื่องาน วันที่ สถานที่ ค่าสมัคร และวันปิดรับสมัคร
- มือทั้งหมด ทีมที่สมัครแล้วในแต่ละมือ / จำนวนทีมที่รับ และตัวสำรอง
- รายชื่อทีมที่ยืนยันแล้ว (ชื่อทีม ชื่อเล่น รูป และระดับของทั้งสองคน)
- ปุ่ม **สมัครผ่าน LINE** เปิด LIFF ไปที่ `/line/tournament`
- ถ้ายังไม่มีงานที่เปิดรับ ให้แสดงหน้า Coming Soon เหมือนเดิม

### 2.2 หน้าสมัครใน LINE `/line/tournament`

1. **เห็นสถานะตัวเองก่อน** ถ้ายังไม่สมัคร เห็นปุ่มสมัคร ถ้าสมัครแล้ว เห็นทีม สถานะ และสิ่งที่ต้องทำต่อ
2. **เลือกคู่** ค้นหาจากชื่อเล่นสมาชิกที่ผูก LINE แล้ว ไม่แสดงคนที่อยู่ในทีมอื่นของงานนี้แล้ว
3. **ระบบบอกมือให้** เช่น "ลงมือ Wine (วัดจาก ต้น · Wine 1386)" มีตัวเลือกขึ้นไปลงมือที่สูงกว่า และบอกว่ามือนั้นเหลือกี่ที่
4. **ตั้งชื่อทีม** ไม่บังคับ ถ้าไม่ตั้ง ใช้ "ชื่อเล่น 1 / ชื่อเล่น 2"
5. **จ่ายค่าสมัครส่วนของตัวเองด้วยเครดิต** แล้วส่งคำชวน
   ถ้าเครดิตไม่พอ มีปุ่มพาไปเติมเครดิต (ใช้หน้าเติมเครดิตเดิม)
6. **คู่ได้คำชวนใน LINE** กดรับแล้วจ่ายส่วนของตัวเอง ทีมเปลี่ยนเป็น "ยืนยันแล้ว" หรือกดปฏิเสธก็ได้

### 2.3 สถานะทีม

```
รอคู่ตอบ ──รับ+จ่าย──▶ ยืนยันแล้ว
   │                      │
   ├─ปฏิเสธ/หมดเวลา──▶ ยกเลิก (คืนเครดิตคนชวน)
   │
   └─(มือเต็ม)──▶ ตัวสำรอง ──มีที่ว่าง──▶ ยืนยันแล้ว
```

- คำชวนหมดเวลาใน 48 ชั่วโมง หรือเมื่อปิดรับสมัคร แล้วแต่อะไรถึงก่อน
- มือเต็มแล้วยังสมัครได้ แต่จะเป็น **ตัวสำรอง** ตามลำดับเวลาที่ทีมยืนยัน
  มีทีมถอนเมื่อไหร่ ตัวสำรองลำดับแรกขึ้นมาแทนเอง และได้ข้อความใน LINE
- **ถอนตัวก่อนปิดรับสมัคร** คืนเครดิตเต็มจำนวนทั้งสองคน ใครในทีมกดถอนก็ได้
- **หลังปิดรับสมัคร** ถอนเองไม่ได้ ต้องให้แอดมินถอนให้ และแอดมินเลือกได้ว่าคืนเครดิตหรือไม่
- 1 คนอยู่ได้ 1 ทีมต่องาน (ดู "ยังต้องตัดสินใจ")

### 2.4 ฝั่งแอดมิน (หน้าใหม่ "ทัวร์นาเมนต์")

- **สร้างงาน** กรอกชื่อ วันที่ สถานที่ ค่าสมัครต่อคน เวลาเปิดและปิดรับสมัคร จำนวนทีมที่รับต่อมือ และค่าลูก
- **ดูรายชื่อทีม** ในแต่ละมือ พร้อมสถานะ ELO และเวลาสมัคร
- **สมัครแทน** สำหรับสมาชิกที่ไม่มี LINE เลือกสองคน แล้วเลือกว่าหักเครดิตหรือรับเงินสด
- **ย้ายมือ / ถอนทีม / คืนเครดิต** ทุกครั้งบันทึกลง activity log
- **ปิดรับสมัครก่อนเวลา** หรือ **เปิดรับต่อ**

## 3. ระบบแข่ง (เฟส 2)

### 3.1 จัดกลุ่ม

- กลุ่มละ 4 ทีมเป็นหลัก ถ้าจำนวนทีมไม่ลงตัว ส่วนที่เหลือเป็นกลุ่มละ 3 ทีม
  (เช่น 10 ทีม = 4+3+3, 13 ทีม = 4+3+3+3, 14 ทีม = 4+4+3+3)
- **ใส่ทีมแบบงู (snake) ตาม ELO รวมของคู่** ทีมเก่งสุดกระจายไปคนละกลุ่ม ทุกกลุ่มหนักพอ ๆ กัน
- เลี่ยงไม่ให้ทีมที่มีคนเดียวกันเคยคู่กันบ่อยมาอยู่กลุ่มเดียวกัน (ทำทีหลังได้)
- แอดมินดูผลจับกลุ่ม สลับทีมเองได้ แล้วกด **ยืนยันกลุ่ม**

### 3.2 รอบแบ่งกลุ่ม

- พบกันหมดในกลุ่ม ลำดับแมท: 1v2 3v4 → 1v3 2v4 → 1v4 2v3
- แต่ละแมทตี **2 เซ็ต เซ็ตละ 21 ไม่มีดิวส์** ชนะ 2–0 ได้ 2 แต้ม เสมอ 1–1 ได้ 1 แต้ม แพ้ 0–2 ได้ 0 แต้ม
- ชนะบายนับเป็น 21–0 ทั้งสองเซ็ต
- **จัดอันดับตามลำดับนี้:** แต้มรวม → ผลต่างคะแนน → คะแนนได้มากสุด → คะแนนเสียน้อยสุด → ผลที่เจอกันเอง

### 3.3 น็อคเอาท์ สายบน / สายล่าง

- ครึ่งบนของตารางกลุ่ม (อันดับ 1–2 ของกลุ่ม 4 ทีม) เข้า **สายบน** ที่เหลือเข้า **สายล่าง**
  ทุกทีมได้แข่งรอบน็อคอย่างน้อย 1 แมท
- จับคู่ไขว้กลุ่ม: A1-B2, C1-D2, A2-B1, C2-D1 … สายล่างใช้แบบเดียวกันกับอันดับ 3 และ 4
- ถ้าจำนวนทีมในสายไม่ใช่ 4/8/16 ทีมอันดับดีที่สุดได้บาย
  ถ้ากลุ่ม 3 ทีมมีแค่อันดับ 1–3 อันดับ 3 ไปสายล่าง
- ตี **2 ใน 3 เซ็ต เซ็ตละ 21 มีดิวส์ ตันที่ 30**
- ไม่มีแมทชิงที่ 3 คนแพ้รอบรองได้ที่ 3 ร่วม

## 4. วันแข่ง (เฟส 3)

- **ตารางแมท** ออกเลขแมทต่อกันทุกมือ ระบบหาสนามว่างให้แมทถัดไป
  คนที่เพิ่งแข่งจบต้องพักอย่างน้อย 10 นาที แอดมินใส่จำนวนสนามจริงในวันงาน แล้วระบบประเมินเวลาจบให้
- **กระดานเรียกแมท** (หน้า live สาธารณะ) บอกว่าเรียกแมทไหนอยู่ และแต่ละสนามแข่งแมทไหน มือไหน รอบไหน สายไหน
  ส่งข้อความ LINE หาทั้ง 4 คนตอนเรียกแมท
- **เรียก 2 ครั้งแล้วไม่มา** แอดมินจับเวลา 5 นาทีแล้วกดปรับแพ้บาย
- **กรอกสกอร์** แอดมินกรอกจากใบคะแนน ทีมที่ชนะเอาใบคะแนนกับลูกมาส่งโต๊ะกลาง
  (หรือให้นักกีฬากรอกใน LINE แล้วอีกฝั่งกดยืนยัน ดู "ยังต้องตัดสินใจ")
- **ค่าลูก** ใช้เครดิตแทนชิป แอดมินกด +1 ลูกที่แมท ระบบหักเครดิตฝั่งละครึ่ง
- อันดับกลุ่มและสายน็อคอัปเดตเองทันทีที่ใส่สกอร์

## 5. หลังจบงาน (เฟส 4)

- หน้า **ผลการแข่งขัน** ต่อมือ บอกแชมป์ รองแชมป์ และที่ 3 ร่วม ของทั้งสายบนและสายล่าง
- แชมป์ขึ้น **หอเกียรติยศ** และได้การ์ดสะสมรุ่นพิเศษ
- แมทในทัวร์นาเมนต์ **นับเข้า ELO** เหมือนเกมปกติ

## 6. ลำดับการทำ

| เฟส | ส่วนที่ทำ | ใช้ได้เมื่อ |
|---|---|---|
| 1 | สร้างงาน + หน้าสมัครใน LINE + รายชื่อทีมบนเว็บ + ค่าสมัครผ่านเครดิต | ประกาศเปิดรับสมัคร |
| 2 | จับกลุ่ม + ออกตารางแมท | ปิดรับสมัคร |

| 4 | ผลการแข่งขัน + หอเกียรติยศ + การ์ด | หลังจบงาน |
