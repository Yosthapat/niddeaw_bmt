# ตั้งค่า Google Sheets (ซิงก์ข้อมูลอัตโนมัติ)

ตั้งค่าครั้งเดียว ใช้เวลาประมาณ 15 นาที ทำบนคอมจะง่ายที่สุด เมื่อเสร็จแล้ว:

- ระบบจะคัดลอกข้อมูลทุกตารางเข้า Google Sheet ของก๊วน **ทุกเช้าวันเสาร์ ประมาณ 03:30** (หลังเลิกเล่นคืนวันศุกร์)
- แต่ละตารางมีแท็บของตัวเอง เช่น สมาชิก แมตช์ ออเดอร์ รายจ่าย ข้อมูลในแท็บเหล่านี้ถูกแทนด้วยของล่าสุดทุกครั้ง
- ทุกครั้งที่ซิงก์ จะได้แท็บ **"สำรอง วันที่"** เพิ่ม 1 แท็บ เก็บย้อนหลัง 8 สัปดาห์ แท็บเก่าไม่ถูกเขียนทับ
- แท็บ **"ประวัติซิงก์"** บอกว่าซิงก์เมื่อไหร่ ใครกด และได้กี่แถว
- กด "ซิงก์ตอนนี้" ในหน้าแอดมิน › ตั้งค่า เมื่อไหร่ก็ได้

> ⚠️ คีย์ service account เปรียบเหมือนรหัสผ่าน **ห้ามส่งในแชท LINE หรือส่งให้ใคร** รวมถึงห้ามส่งให้ Claude ด้วย ให้วางใน Render อย่างเดียว

---

## 1. สร้าง Google Sheet

1. เปิด <https://sheets.new> ด้วยบัญชี Google ของก๊วน หรือของแอดมินหลัก
2. ตั้งชื่อไฟล์ เช่น `นิดเดียว BMT – ข้อมูล`
3. คัดลอกลิงก์ของชีตเก็บไว้ (ลิงก์หน้าตาแบบ `https://docs.google.com/spreadsheets/d/xxxx/edit`)

ชีตนี้มีชื่อและเบอร์โทรของลูกค้า **แชร์ให้เฉพาะแอดมิน** ห้ามตั้งเป็น "ทุกคนที่มีลิงก์"

## 2. สร้าง service account ใน Google Cloud (ฟรี ไม่ต้องผูกบัตร)

1. เปิด <https://console.cloud.google.com> แล้ว login ด้วยบัญชี Google
2. ด้านบนกดเลือกโปรเจกต์ › **New project** › ตั้งชื่อ `niddeaw-bmt` › **Create** แล้วเลือกโปรเจกต์นั้น
3. เปิด <https://console.cloud.google.com/apis/library/sheets.googleapis.com> แล้วกด **Enable**
4. ไปที่ **IAM & Admin › Service Accounts** › **Create service account**
   - Name: `niddeaw-sync` › **Create and continue**
   - ขั้น Permissions และ Principals with access ข้ามได้เลย › **Done**
5. กดเข้าไปใน service account ที่เพิ่งสร้าง › แท็บ **Keys** › **Add key › Create new key** › เลือก **JSON** › **Create**
   - เครื่องจะดาวน์โหลดไฟล์ `.json` มา 1 ไฟล์ ใช้ในขั้นต่อไป

ถ้าขึ้นว่าสร้างคีย์ไม่ได้ ("key creation is disabled") แปลว่าบัญชีอยู่ใต้องค์กรที่ปิดฟีเจอร์นี้ไว้ ให้ใช้บัญชี Gmail ส่วนตัวแทน

## 3. ใส่ค่าใน Render

เปิด Render › service `niddeaw-bmt` (backend) › **Environment** › **Add environment variable** เพิ่ม 3 ตัว:

| Key | Value |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | เปิดไฟล์ `.json` จากขั้น 2 ด้วย Notepad หรือ TextEdit แล้ว **คัดลอกทั้งไฟล์** มาวาง |
| `SHEETS_SPREADSHEET_ID` | ลิงก์ของ Google Sheet จากขั้น 1 วางทั้งลิงก์ได้เลย |
| `SHEETS_SYNC_SECRET` | ข้อความสุ่มยาว ๆ ที่คิดขึ้นเอง 30 ตัวขึ้นไป (ภาษาอังกฤษกับตัวเลข) เก็บไว้ใช้อีกครั้งในขั้น 5 |

กด **Save changes** แล้วรอ Render deploy ใหม่ 1–3 นาที

เมื่อวางคีย์ใน Render เสร็จแล้ว ลบไฟล์ `.json` ออกจากเครื่องได้เลย ถ้าทำหายก็สร้างใหม่ได้จากขั้น 2.5

## 4. แชร์ชีตให้ service account

1. เปิดหน้าแอดมิน › **ตั้งค่า** › หัวข้อ **Google Sheets**
   - จะเห็นอีเมลของ service account เช่น `niddeaw-sync@niddeaw-bmt.iam.gserviceaccount.com` กด **คัดลอก**
2. กลับไปที่ Google Sheet › **แชร์** › วางอีเมลนั้น › เลือก **ผู้แก้ไข** › เอาติ๊ก "แจ้งเตือนผู้คน" ออก › **แชร์**
3. กลับมาหน้าตั้งค่า กด **ซิงก์ตอนนี้** แล้วเปิดชีตดู ควรเห็นแท็บของทุกตาราง

## 5. เปิดการซิงก์อัตโนมัติทุกสัปดาห์

1. เปิด GitHub repo `niddeaw_bmt` › **Settings › Secrets and variables › Actions** › **New repository secret**
2. Name: `SHEETS_SYNC_SECRET` Secret: ข้อความเดียวกับที่ใส่ใน Render ขั้น 3 › **Add secret**
3. ทดสอบ: แท็บ **Actions** › **Weekly Google Sheets sync** › **Run workflow**
   - ผ่านแล้วจะเห็นแถวใหม่ "อัตโนมัติ (ทุกเช้าวันเสาร์)" ในแท็บประวัติซิงก์

## ถ้ามีปัญหา

| ข้อความในหน้าตั้งค่า | แก้ยังไง |
|---|---|
| เปิด Google Sheet ไม่ได้ — แชร์ชีตให้ … แล้วหรือยัง | ทำขั้น 4 ใหม่ ต้องเลือกสิทธิ์เป็น **ผู้แก้ไข** ไม่ใช่ผู้ดู |
| Google ไม่ให้เข้าสู่ระบบด้วย service account นี้ | คีย์ถูกลบหรือวางไม่ครบ สร้างคีย์ใหม่ตามขั้น 2.5 แล้ววางใน Render ใหม่ |
| GOOGLE_SERVICE_ACCOUNT_JSON อ่านไม่ได้ | ต้องวางเนื้อหาทั้งไฟล์ ตั้งแต่ `{` ตัวแรกถึง `}` ตัวสุดท้าย |
| SHEETS_SPREADSHEET_ID ไม่ถูกต้อง | วางลิงก์ของชีตให้ครบทั้งลิงก์ |
| ยังไม่ได้เปิด Google Sheets API ในโปรเจกต์ | กด Enable ในขั้น 2.3 (ถ้าเพิ่งกด รอสัก 2–3 นาทีแล้วลองใหม่) |

ไฟล์ ZIP จากปุ่ม "ดาวน์โหลดไฟล์สำรอง" ยังเป็น backup หลักสำหรับกู้คืนข้อมูล แนะนำให้ดาวน์โหลดเก็บไว้เดือนละครั้งเหมือนเดิม
