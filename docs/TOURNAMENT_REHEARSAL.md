# ซ้อมวันแข่ง NIDDEAW CUP

ซ้อมครั้งเดียวให้ทีมงานได้กดจริงทุกหน้าจอ ด้วยอุปกรณ์จริงในสนามจริง ก่อนวันแข่ง
ปัญหาที่เจอวันซ้อม = ปัญหาที่ไม่ต้องเจอต่อหน้าผู้เล่น 100 กว่าคน

- **เมื่อไหร่:** หลังปิดรับสมัคร (6 ก.พ. 2570) และก่อนวันแข่ง (20 ก.พ. 2570) — แนะนำคืนก๊วนปกติช่วง 8–15 ก.พ.
- **ใช้เวลา:** ประมาณ 1.5 ชั่วโมง
- **ใช้ใคร:** ทีมงานวันจริงทุกคน + ผู้เล่นขาประจำ 8–16 คน (4–8 ทีม)

---

## ⚠️ กฎ 2 ข้อของงานซ้อม

งานจริง **NIDDEAW CUP #1** เปิดรับสมัครอยู่ งานซ้อมต้องไม่ไปชนกับมัน

1. **งานซ้อมต้องอยู่สถานะ "ร่าง" ตลอด** — ห้ามเปลี่ยนเป็น "เปิดรับสมัคร" / "ปิดรับสมัคร"
   ไม่งั้นหน้าเว็บ, การ์ดหน้าแรก และ LINE อาจไปโชว์งานซ้อมแทนงานจริง
2. **ห้ามเปลี่ยนเป็น "กำลังแข่ง" หรือ "จบแล้ว"** — งานที่กำลังแข่งหรือจบแล้วลบไม่ได้

งานสถานะ "ร่าง" ทำได้ทุกอย่างฝั่งแอดมิน: สมัครแทนที่โต๊ะ, จับกลุ่ม, ออกตาราง, ประกาศตาราง, เช็คอิน, เรียกลงสนาม, กรอกผล, คูปอง, พิมพ์
จอทีวีก็เปิดดูได้ผ่านลิงก์พิเศษ (ปุ่ม "เปิดจอทีวี" ในหน้าวันแข่งใส่ให้เอง)

สิ่งที่ซ้อมไม่ได้: **หน้า LINE ของผู้เล่น** และ **หน้า niddeaw.fyi/tournament** (ทั้งสองหน้าจะยังโชว์งานจริง) — ส่วนนี้ทดสอบไปแล้วตอนเปิดรับสมัคร

---

## 1. เตรียมงานซ้อม (ทำล่วงหน้า 1 วัน, ~15 นาที)

แอดมินฝั่งทัวร์นาเมนต์ → แท็บ **งาน**

1. สร้างงานใหม่ ชื่อ `ซ้อมวันแข่ง` วันที่ = วันซ้อม
2. ตั้งค่า:
   - **สนาม** = จำนวนคอร์ทที่จะใช้ตอนซ้อม (เช่น 2–3)
   - **พักระหว่างแมท** = 0–2 นาที (ซ้อมจะได้ไม่ต้องรอ)
   - **ราคา / คูปอง** = เหมือนงานจริง (จะได้เห็นตัวเลขจริงตอนขายคูปอง)
   - **มือ:** มือเดียว ช่วง ELO กว้าง ๆ, จำนวนเกมขั้นต่ำ = 0
3. **อย่ากดเปิดรับสมัคร** — ปล่อยไว้ "ร่าง"

แท็บ **ทีม** → **สมัครแทน**

4. ใส่ 4–8 ทีมจากคนที่จะมาซ้อม เลือกจ่าย **เงินสด** (เงินนี้อยู่ในงานซ้อมอย่างเดียว ลบงานแล้วหายไปด้วย)
5. ตั้งชื่อทีมซ้ำกันสัก 2 ทีม (เช่น `ทีม A` ในชื่อคล้ายกัน) เพื่อดูว่าโต๊ะแยกออกไหม

แท็บ **กลุ่ม & ตาราง**

6. จับกลุ่ม → ออกตารางแมท → **ประกาศตาราง**

## 2. เช็คอุปกรณ์ (ก่อนเริ่มซ้อม 30 นาที)

| ของ | เช็คอะไร |
|---|---|
| **ทีวี + โน้ตบุ๊ก** | ต่อ HDMI, เปิดหน้า **วันแข่ง → เปิดจอทีวี**, กด `F11` เต็มจอ, ยืนอ่านจากปลายสนามได้ไหม |
| โน้ตบุ๊ก | ปิดโหมดพักหน้าจอ/ปิดฝา, เสียบสายชาร์จ (หน้าจอทีวีขอให้เครื่องไม่ดับเอง แต่บางเครื่องไม่ยอม) |
| **Wi-Fi ในสนาม** | ทุกเครื่องเปิดเว็บได้ไหม, มือถือเปิด **hotspot สำรอง** ไว้ 1 เครื่อง |
| **ปริ้นเตอร์** | หน้า **วันแข่ง → พิมพ์ตาราง & ใบบันทึกคะแนน** ลองพิมพ์ตารางแมท 1 ชุด + ใบบันทึกคะแนน 2 แผ่น |
| มือถือแอดมิน | ล็อกอินครบทุกคน, ชาร์จเต็ม, มีพาวเวอร์แบงก์ |
| ปากกา, คลิปบอร์ด | สำหรับกรรมการแต่ละคอร์ท |

> เซิร์ฟเวอร์ฟรีของ Render หลับได้ — เปิดเว็บทิ้งไว้ก่อนเริ่ม 15 นาที ครั้งแรกอาจช้า 30–60 วินาที

## 3. ลำดับซ้อม (~60 นาที)

แบ่งหน้าที่แบบวันจริง:

- **โต๊ะลงทะเบียน** — เช็คอิน, ขายคูปอง
- **คนเรียกสนาม** — เรียกแมทลงคอร์ท, เรียกซ้ำ
- **คนกรอกผล** — รับใบคะแนนที่เซ็นแล้ว กรอกเข้าระบบ
- **กรรมการคอร์ท** — จดคะแนนลงใบ ให้หัวหน้าทีมเซ็น

### 3.1 เช็คอิน (หน้า วันแข่ง → แท็บ เช็คอิน)

- [ ] ก่อนเช็คอินใครเลย: แท็บ **สนาม** เสนอแมทให้ตามปกติ
- [ ] เช็คอินทีมแรก → แท็บสนามเสนอเฉพาะแมทที่ **ทั้งสองทีมมาแล้ว**
- [ ] เช็คอินผิดทีม → กด **ยกเลิก** ได้
- [ ] ปุ่ม **ยังไม่มา** โชว์เฉพาะทีมที่ยังไม่มา, ช่องค้นหาหาด้วยชื่อเล่นผู้เล่นได้
- [ ] ทีมที่ยังไม่มา: เลือกเองจาก "เลือกแมทอื่น" ได้ (มีคำว่า "ยังไม่มา" ต่อท้าย)

### 3.2 เรียกลงสนาม (แท็บ สนาม)

- [ ] เรียกแมทลงทุกคอร์ท → จอทีวีขึ้นภายใน 15 วินาที
- [ ] **เรียกซ้ำ** (ทีมไม่มา) → จำนวนครั้งที่เรียกขึ้น
- [ ] **ยกเลิกการเรียก** แล้วเรียกใหม่ลงคอร์ทอื่น
- [ ] ทีมที่อยู่บนคอร์ทแล้ว ถูกเรียกซ้อนคอร์ทอื่นไม่ได้

### 3.3 ผลการแข่ง

- ซ้อมไม่ต้องตีจนจบเกม — ตีสักพักแล้ว **แต่งคะแนนตามกติกา** (รอบกลุ่ม 2 เซ็ต, น็อค 2 ใน 3)
- [ ] กรรมการจดลงใบบันทึกคะแนน, หัวหน้าทีมทั้งสองเซ็น, ส่งโต๊ะ
- [ ] กรอกผล + จำนวนลูกที่ใช้ → จอทีวีขึ้นใน "ผลล่าสุด"
- [ ] ลองกรอกคะแนนผิดกติกา (เช่น 21–20) → ระบบต้องไม่รับ
- [ ] แก้ผลที่กรอกผิด (แท็บ ผลแข่ง → แก้ผล)
- [ ] **ปรับแพ้บาย** 1 แมท
- [ ] หลังพักครบ ทีมที่เพิ่งเล่นกลับมาอยู่ในคิวอีก

### 3.4 คูปองลูก (แท็บ คูปอง)

- [ ] ทีมที่คูปองใกล้หมดขึ้นสีเหลือง
- [ ] **ขายชุดเพิ่ม** 1 ชุด (เงินสด) และ (โอน + แนบสลิป)
- [ ] **รับคืนคูปอง** ที่เหลือ → ดูยอดในหน้า **รายรับรายจ่าย** ตรงไหม

### 3.5 รอบน็อค

- [ ] เล่นรอบกลุ่มจนครบ → ระบบเติมทีมเข้าสายบน/ล่างเอง
- [ ] เล่นจนได้แชมป์ → จอทีวีโชว์แชมป์เต็มจอ

## 4. ซ้อมเหตุฉุกเฉิน (~15 นาที)

| สถานการณ์ | ทำอย่างไร |
|---|---|
| **เน็ตล่ม** | ปิด Wi-Fi โน้ตบุ๊ก → จอทีวีขึ้น "เชื่อมต่อไม่ได้" แต่ข้อมูลล่าสุดยังอยู่ → เดินเกมต่อด้วย **ตารางแมทที่พิมพ์ไว้** + ใบบันทึกคะแนน → เน็ตกลับมาค่อยกรอกย้อนหลัง |
| **มือถือแอดมินแบตหมด** | ล็อกอินเครื่องอื่นแทนได้ทันที (ข้อมูลอยู่ที่เซิร์ฟเวอร์) |
| **แอดมิน 2 คนกดพร้อมกัน** | ให้ 2 คนเรียกแมทลงคอร์ทเดียวกันพร้อมกัน → ต้องผ่านแค่คนเดียว อีกคนเห็นข้อความเตือน |
| **ทีมไม่มา** | เรียกซ้ำ 2 ครั้ง → ปรับแพ้บายตามกติกา |
| **ทีวีดับ/รีสตาร์ท** | เปิดลิงก์จอทีวีใหม่ ทุกอย่างกลับมาเอง |

---

## 5. หลังซ้อม

1. คุยกันสั้น ๆ: อะไรช้า อะไรงง ใครต้องการปุ่มอะไรเพิ่ม → ส่งมาแก้ก่อนวันจริง
2. **ลบงานซ้อม:** แท็บ **งาน** → เลือก `ซ้อมวันแข่ง` → ลบ (พิมพ์ชื่องานยืนยัน)
   ทีม เงินสด แมท คูปอง ของงานซ้อมหายไปทั้งหมด งานจริงไม่โดนอะไร
   ถ้าลบไม่ได้ แปลว่าสถานะถูกเปลี่ยนเป็น "กำลังแข่ง/จบแล้ว" — ส่งมาให้ช่วยลบ
3. เก็บใบบันทึกคะแนนที่พิมพ์เกินไว้ใช้วันจริงไม่ได้ (เลขแมทจะไม่ตรง) — พิมพ์ใหม่หลังออกตารางงานจริง

## เช้าวันแข่งจริง (เช็คลิสต์ย่อ)

- [ ] งานจริงประกาศตารางแล้ว
- [ ] เปลี่ยนสถานะงานเป็น **กำลังแข่ง** ตอนเริ่ม
- [ ] พิมพ์ตารางแมท 2 ชุด (โต๊ะ + บอร์ดหน้าสนาม) และใบบันทึกคะแนนแมทรอบกลุ่มทั้งหมด
- [ ] เปิดจอทีวี, เต็มจอ, ปิดโหมดพักหน้าจอ
- [ ] เปิดเว็บทิ้งไว้ 15 นาทีก่อนเริ่ม (ปลุกเซิร์ฟเวอร์)
- [ ] hotspot สำรองพร้อม
- [ ] เริ่มเช็คอินทีมที่โต๊ะตั้งแต่ทีมแรกมาถึง
- [ ] จบงาน → เปลี่ยนสถานะเป็น **จบแล้ว**
